Connect your ChatGPT tab
The companion uses the ChatGPT account already signed in to your browser. No API key or cookie export.
  1. In Chrome or Chromium, open chrome://extensions and enable Developer mode.
  2. Choose Load unpacked and select extension inside the Privacy Chat folder.
  3. Open ChatGPT in that browser and sign in normally.
  4. Reload this page. The companion reuses one background ChatGPT tab and returns completed replies here automatically.
This copy is configured to filter through a remote model over the internet. Your text reaches that host before it is filtered; ChatGPT still only ever receives the filtered version.
The filter runs through the Ollama service set in config.json beside the app (local_ai). Loopback and private addresses are accepted by default; a public https host requires allow_remote_ai. Originals and the restoration map stay in this local app’s memory; ChatGPT receives the filtered conversation. Closing a chat clears its map. Chrome may throttle a fully hidden background tab; if that happens, leave its window open behind Privacy Chat.
